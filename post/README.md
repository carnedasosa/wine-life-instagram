## File

- `png/`: le 26 slide pronte da caricare su Instagram (1080×1350), foto comprese.
- `foto/`: le tre foto col flash usate nei post 03, 05 e 08.
- `NN-nome/`: gli HTML sorgente, basati su `../templates/wl.css`. Per cambiare un testo si modifica l'HTML e si riesporta dalla radice con `bash templates/export.sh post/NN-nome`.
- `pdf/`: versione PDF dei post (senza foto). Canva non si usa più: nell'import sostituiva i font.
